# 78-clubs — clubs without chat, a shared weekly goal (2026-10-10) + the official club
- Firebase: `clubs/<id>={name:<presetIndex>, emoji, code, created, members:{<fbKey>:{name,lv,g,w,m,wk,t}}, week:{key,goals}}`, `clubCodes/<CODE>=<id>`; `users/<key>.club` via the heartbeat. Create 30💎 (admins free), join by a 6-char code, leave, max 20. Preset names ×24 (4 languages) + 12 emojis — no free text.
- Weekly goal: target = max(30, 15 × members); each real match PATCHes my member node (goals/wins/matches, week key). Prize once per week **per club** (`prog.clubPrizeOf={<clubId>:weekKey}`, the old `prog.clubPrize` migrates) for members with ≥5 matches: silver chest + 10💎, 2× target → gold chest.
- UI: `#club-modal` with two tabs (`#club-tabs`: "🏟️ המועדון שלי" / "📣 <emoji> <official name>", hidden when no official club exists — the admin always sees it), club / create / join views on the first tab, `#home-club` pill (the one entry; no more-sheet button) ("🦁 83/150"; "📣 83/150" when there is no personal club but an official one; shares a row with the league pill). Invite via the social share helper with a `?club=CODE` deep link (asks before joining).
- Offline: every `fbReq` undefined → "אין חיבור", local counters kept and re-pushed (`dirty`).

## The official club (admin-run, everyone is in automatically — in ADDITION to the personal club)
- Server: `official/club={id, name:<free text ≤24>, emoji, msg:<free text ≤300>, by:<admin name>, auto:true|false, code, updated}`; `clubs/<id>` is a normal club node with `name:<string>` and `official:true`. `name`/`msg` are the only free text in the game → rendered through `esc()` only (also in the tab label / title through `textContent`). Writes are gated client-side with `isAdmin()`; the rules are open today (snippet appended to PLAN Appendix A, TODO for the hardening).
- Membership: on load/home `officialSync()` (throttled, ≤1 GET of `official/club` per hour via `prog.officialSeen`; 5-minute retry when offline) and on every modal open `officialOpenSync()` (1 GET of `official/club` + 1 GET of `clubs/<id>`, cached 10 min like the personal club): when `auto` is on, my member node is PATCHed once (`clubs/<id>/members/<fbKey(me)>`, same shape as any member) and `prog.officialId` is stored. A player without a name is simply not added (no prompt). After each real match both clubs get a PATCH (`clubPush` + `officialPush`, both through `clubMemberBody`). No leave button while `auto` is on; `auto` off → nobody new is added, members may leave (node deleted, `prog.officialId` cleared) and rejoin by the code (`clubJoin` detects `official:true` and joins the official club next to the personal one — no member cap, no "already in a club").
- Official tab: the admin's message as a speech-bubble board ("📣 הודעה מ-<by>"), code (copy/share), days left, the goal bar (target = max(50, 10 × members)), prize line, members count, the top 20 by goals (+ my row) and "ועוד N חברים", claim (same rules, keyed per club), invite, ⚙️ (admin) and leave (auto off only). Non-members see the board + "join" (auto on) / "join with a code" (auto off, a join form inside the tab).
- Admin form (`CLUB.oview='admin'`, "⚙️ המועדון הרשמי", only rendered for `isAdmin()`, every write re-checks): name input (maxlength 24) + 13 emoji chips → create (free) or rename (PATCHes `official/club` and `clubs/<id>`), a textarea (maxlength 300) → "📣 שמור הודעה", a `.switch` "כולם במועדון אוטומטית" → `auto`. No delete control (the admin can create a new one; the old membership is dropped on the next GET).
- Public: `officialInfo officialId officialTarget officialStats officialMe officialSync officialOpenSync officialGet officialEnsure officialRefresh officialPush officialJoinNow officialJoinWith officialLeave officialClaim officialInvite officialCreate officialRename officialSetMsg officialSetAuto officialNormName officialNormMsg officialSan clubClaimFor clubPrizeOf clubDisplay clubRenderOfficial clubRenderTabs clubRerender`; `ECON.clubs.oGoalPer/oGoalMin/oTop/oSeenMs/oRetryMs/nameMax/msgMax`, `OFFICIAL_EMOJIS`.
- `prog`: `prog.official` (sanitised copy + `tot/target/n` cache for the pill), `prog.officialId`, `prog.officialMe={wk,g,w,m,dirty?}`, `prog.officialSeen`, `prog.clubPrizeOf`.
- Public (personal): `myClub clubTarget clubWeekStats(data, ctx?) clubRefresh clubCreate clubJoin clubLeave clubClaim clubInvite clubOpen(view|'official') clubClose clubRender clubHomePill` and more; state `CLUB` (`tab`, `oview`, `odata/ofetched/ooffline/oloading/osync/ogone` for the official club); `ECON.clubs`. `prog.club={id,code,name,emoji,joined,me:{wk,g,w,m}}`.
