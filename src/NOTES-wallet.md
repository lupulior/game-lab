# 92-wallet + 93-name — no maximums, big numbers, the word "XP" is gone, the name is mandatory (2026-10-10)
- `ECON.capCoins / capSunday / gemWeekCap / matchMax` are `Infinity` (the owner wants no maximum); a finite value brings the cap back and the end card's cap row (40-endcard) returns. Keys keep `keyCap` 10. `coinCapLeft()` returns Infinity, `payout` only clamps finite values, `walletNum(v)` reads whole numbers safely above 2^31.
- `fmtNum(n)`: <1e6 → `12,345`; ≥1e6 → `1.5 מיליון` / `100 מיליון`; ≥1e9 → `מיליארד` (`num.million`, `num.billion` in 4 languages; `fmtXp` in the core delegates to it). `fmtNumHTML(n)` wraps the word in `<small class="mag">`. 92-wallet wraps `updateXpBadge`, `shopWallet`, `buildChests`, `updatePresenceUI`, `buildAch`, `viewFriend` to render pills with `fmtNumHTML` + `fitText`, so nothing overflows. Public: `walletPill(el, icon, n)`, `walletBadges()`.
- "XP" is gone from every string: coin amounts say 🪙 מטבעות, level points say ⭐ נקודות (`end.xp`, `xp.gain`, `chests.c.xp`). `daily.desc` no longer prints a number ("ניצחון = 🪙 מטבעות כפולים + 🏆").
- 93-name: nobody plays without a name. `Hooks 'home'` / `'screen'('home')` → `askNameIfMissing()`; chained gates (`nameGate()`) on `homePlay startGame startOfflineMatch openFriends mpLobby mpHost mpJoin startTraining` and capture-phase click gates on the play buttons; a MutationObserver reopens `#name-modal` when a back press closes it while nameless. Public: `nameOk() nameAsk() nameGate()`. `src/test/00-boot.js` sets a name so later suites play as a returning player.
